# Safika Sultana Portfolio Platform

This repository contains a monorepo with a premium dark-themed Next.js portfolio and a NestJS API backend.

## Stack

- Frontend: Next.js App Router, TypeScript, Tailwind CSS
- Backend: NestJS + Express, Swagger, Pino, Throttling
- Data: PostgreSQL / Supabase SQL migration examples

## Getting started

```bash
npm install
npm run dev
```

The web app runs at http://localhost:3000 and the API runs from the `apps/api` workspace.

## Notes

This project uses sample portfolio content and a realistic production-ready structure for a premium portfolio CMS. It is intended to be extended with your own admin credentials, Supabase project settings, and deployment secrets.
